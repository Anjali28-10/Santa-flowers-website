# Santa Flowers Website

An e-commerce website for selling flower bouquets, designed to provide users a smooth shopping experience. Customers can browse flower collections, add products to the cart, and place orders. Admins can manage products, view orders, and update inventory.

---

## Features

- Browse a variety of flower bouquets
- Add items to cart and manage quantities
- Place orders online
- Admin panel to manage products and orders
- User-friendly interface with responsive design

---

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java Servlets, Spring Framework
- **Database:** MySQL
- **Authentication & Security:** JWT (if used)
